# All 3D assets are produced by scripting Blender

The user does not want to open Blender, and code-built primitive characters were rejected as not impressive enough. Every character, prop, and keyframed animation is generated by agent-written `bpy` scripts run headless, exported as GLB, and loaded by the Engine. Scripts are the source of truth and live in the repo; exported GLBs are build artefacts. The trade-off is a steeper pipeline than primitives or asset packs, in exchange for a look that is fully ours and gags that agents can author end to end.
